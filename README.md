
# Minha IA de Vídeos

Uma inteligência artificial em desenvolvimento para criar vídeos automaticamente a partir de textos e histórias.

## Objetivo

Desenvolver meu próprio aplicativo de geração de vídeos utilizando modelos de inteligência artificial de código aberto.

## Funcionalidades planejadas

- Criar histórias a partir de texto.
- Dividir histórias em cenas de 8 segundos.
- Criar personagens e cenários.
- Gerar vídeos com inteligência artificial.
- Adicionar narração, músicas e legendas.
- Juntar as cenas automaticamente.
- Exportar vídeos em formato MP4.
- Criar vídeos para YouTube, TikTok e outras plataformas.

## Tecnologias

- Python
- FastAPI
- Modelos de IA de código aberto
- ComfyUI
- FFmpeg

## Filosofia do projeto

O objetivo é desenvolver uma solução própria, priorizando ferramentas gratuitas e modelos de código aberto, sem depender de serviços pagos de geração de vídeos.
